Protected Peripheral Vectors (PeripheralInstinct Research)

Logitech HID++

Blocks Feature 0x8100 onboard memory writes, HID++ 1.0 subId 0x90/0x91 macro memory overwrites, and Unifying CVE-2019-13055 key dump commands.

CH57X Keyboards

Blocks WCH CH57X macropad Report 3 reprogramming commands (0xa1 / 0xaa) used to inject silent Run/PowerShell keyboard sequences.

Zelotes & Speedlink

Intercepts Holtek-based gaming mice Feature 7 memory bank writes (opcodes 0x03, 0x09, 0x10) that remap mouse click buttons to malicious keyboard shortcuts.

WebMIDI SysEx

Guards against Novation Launchpad MK2 and SysEx controller firmware overwrite frames (F0 ... F7) capable of re-flashing device controllers.

WebSerial Modems

Inspects serial streams for Hayes AT modem commands (AT+CMGS, AT+CPIN, AT^FLASH) attempting SMS exfiltration or modem hijacking.

Roccat & Redragon

Blocks multi-report configuration dumps on Roccat Kone Aimo and Redragon peripherals that rebind profiles to keystroke sequences.
